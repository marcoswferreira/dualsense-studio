Emulates Xbox 360, DualShock 4, or Virtual DualSense (uhid / usbip-win2) with automatic HidHide cloaking and game-exit restore.

Capabilities

Every DualSense subsystem, unified

Engineered as a standalone single-instance Rust daemon with an embedded React studio, native Windows System Tray, and automatic GitHub release updates.

01 / MAPPING

Curves, Touchpad Mouse & Gyro

Per-stick inner/outer/anti-deadzones, hair-trigger thresholds, paddle & NextProfile remaps, EMA gyro smoothing, toggle activation, and OS mouse/scroll control.

02 / AUDIO DSP

Live OS Loopback Capture

Windows WASAPI COM loopback and Linux parec capture feed the real-time 3 kHz haptic synthesizer with adjustable gain, cutoff, and L/R balance.

03 / CLOAKING

Automatic HidHide Sync

Detects HidHideCLI.exe, allowlists DualSense Studio, and automatically hides the physical controller in Xbox 360 / DS4 mode to eliminate double-input.

04 / AUTOMATION

Per-Game Profiles & Restore

ProcessProfileWatcher switches triggers and RGB when a matching game launches, snapshots your previous setup, and restores it cleanly when the game exits.

05 / PROTOCOLS

Cemuhook DSU & DualSenseX

Built-in 100 Hz Cemuhook motion server (:26760) for Cemu/Dolphin/Ryujinx plus DualSenseX JSON UDP listener (:6969).

06 / DIAGNOSTICS

SSE Stream & Log Bundle

Low-jitter Server-Sent Events (/api/dualsense/events) with polling fallback, rotating dualsense-studio.log, and one-click Copy Diagnostics.

Architecture & Telemetry

Predictable data path from HID to game

Shared lock-free/RwLock state coordinates HID input decoding, 40 Hz lightbar animations, virtual device output, and browser/app telemetry without blocking the 1000 Hz input loop.

Signal & Feedback Pipeline

HID IN USB 0x01 / BT 0x31 decoded with transport detection, battery state, and CRC32 check.
MAPPER Applies deadzones, response curves, EMA gyro, Toggle, and Touchpad Mouse.
EMULATE Routes to ViGEmBus (X360/DS4) with HidHide cloak or Virtual DualSense.
HID OUT Merges 40 Hz Lightbar, Adaptive Triggers, and 0x32 Audio Haptics.
SSE UI Streams live input & status frames to the React Studio on :48080.

Installation

Ready in under two minutes

Use the signed-style Windows Inno Setup installer for one-click setup with optional ViGEmBus, HidHide, and usbip-win2 drivers, or build directly from source.

Windows Setup Installer (Recommended)

Download dualsense-studio-v0.2.0-windows-x86_64-setup.exe from GitHub Releases. Includes System Tray integration, single-instance guard, and auto-updater. 

# Launch quiet in Windows System Tray
dualsense-studio.exe --tray

# Or open the Studio UI immediately
dualsense-studio.exe --open-ui

Linux & Build from Source

Requires Rust stable, Node.js 22+, and libudev-dev on Linux. 

cd frontend && npm ci && npm run build && cd ..
cargo build --workspace --release
./packaging/linux/install.sh
